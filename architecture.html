System Architecture

MLB Scoreboards

A Devvit Web app: a live MLB scoreboard rendered inside a Reddit game thread, with the threads themselves posted automatically. Everything below reflects the code as it currently ships.

Data source

Straight from the MLB Stats API. No wrapper library, no SDK, no third-party service — plain HTTPS calls to statsapi.mlb.com.

The client never calls MLB directly. It calls this app's own endpoints, and the server fetches upstream and caches the response in Redis, so a hundred readers on one thread collapse into one upstream call every few seconds.

Data path

Four things can wake the app: someone viewing a post, a moderator using the menu, the once-a-minute scheduler, or a Reddit event trigger. All of them land on the same server.

Endpoints

Everything the client can call, and what each one does upstream. Cached routes serve from Redis first and only reach MLB when the entry has expired.

RoutePurposeUpstreamCache
GET /api/game/:pk Full live feed — score, count, box, plays v1.1 feed/live 8s
GET /api/winprob/:pk Win probability series v1 winProbability 12s
GET /api/schedule Day's games — no longer called by the client v1 schedule 30s

Life of a game thread

Order matters here — each step depends on the one before it.

1
A moderator posts the day's threads
The menu item fetches today's schedule in US Eastern, filtered to the configured team.
2
One post per game
Each game without a posted: lock gets a thread, then the app writes the render binding and the lock.
3
A reader opens the post
The web view asks /api/post-game which game it belongs to. No binding means the thread has aged out, and it shows the ended card instead.
4
The scoreboard refreshes every 10 seconds
Polling pauses when the post scrolls out of view and stops entirely once the game is over.
5
The game ends
The client reports the final once. The server re-verifies it upstream, checks the game is under 36 hours old and that auto-posting is on, then posts the wrap.
6
The sweeper catches anything missed
Every minute, a job re-checks today and yesterday for finals and postponements — so a thread nobody had open still gets its follow-up.
7
Removing a post frees it
Delete or remove clears that post's locks, so the same game can be posted again.
